# Деберц 2×2 — счётчик очков

Веб-приложение (мобильное в первую очередь) для подсчёта очков в игре
«деберц» 2×2. Один игрок за столом ведёт счёт на телефоне — остальное
приложение считает само.

## Как играть

1. **Настройка игры**: вводятся названия двух команд (по умолчанию
   «Команда А» / «Команда Б»), выбирается цель — 501 или 1001 очко, а
   также штрафы за «БЗ» (без взяток) и за «3 байта».
2. **Каждый раунд** вводится:
   - сумма очков раздачи — один из пресетов (162/182/202/212/232/252)
     либо произвольное значение через «Своё значение»;
   - какая команда играла (объявила контракт);
   - очки одной из команд — очки второй команды приложение досчитывает
     само от общей суммы раздачи.
3. **БЗ** определяется автоматически: если у какой-то команды выходит
   0 очков, победитель забирает банк раздачи целиком, а у команды с БЗ
   дополнительно вычитается штраф из её собственного счёта.
4. **Байт**: если команда, объявившая игру, набрала очков меньше
   соперника — все очки раздачи уходят сопернику. Каждый 3-й байт одной
   команды (не обязательно подряд) добавляет ей отдельный штраф.
5. **Висячий байт**: если играющая и принимающая команды набрали
   поровну, доля принимающей выплачивается сразу, а доля играющей
   замораживается. Судьба заморозки решается следующим же раундом: если
   замороженная команда наберёт в нём больше очков, чем соперник —
   заморозка прибавляется сверху, иначе сгорает.
6. Игра завершается, когда одна из команд достигает выбранной цели
   (501/1001), и приложение показывает победителя.

Счёт хранится только в рамках текущей сессии браузера (sessionStorage) —
обновление страницы его сохраняет, закрытие вкладки сбрасывает.

## Разработка

```bash
npm install
npm run dev
```

Стек: Next.js (App Router) + TypeScript + Tailwind CSS. Вся логика
подсчёта — чистые функции в `src/lib/gameEngine.ts`.
